# UI Specs Directory

This folder contains UI specification documents for the React Native migration.

## Naming Convention

```
{number}_{page_or_component_name}.md
```

**Examples:**
- `01_welcome_page.md` - Welcome/landing page
- `02_home_page.md` - Conversational home page
- `03_word_card_game.md` - Word test game screen
- `04_nav_bar.md` - Bottom navigation component

**Rules:**
1. Use 2-digit prefix for ordering (01, 02, 03...)
2. Use lowercase with underscores
3. End with `_page` for screens, `_component` for reusable components
4. One file per page/major component
